# Arissa's Portfolio

This repository contains my personal portfolio website, created to share my background, skills, projects, and experience as I prepare for my internship.

The website was built using HTML, CSS, and JavaScript. I went with a simple retro-inspired design using soft pink and yellow, while keeping the layout easy to navigate on both desktop and mobile.

## About the Website

The portfolio includes the following sections:

- **Home** – A short introduction
- **About Me** – My background and interests
- **Education** – Academic background
- **Skills** – Technical and other relevant skills
- **Projects** – Projects I've worked on
- **Experience** – Relevant experience
- **Achievements** – Academic and personal achievements
- **Contact** – Contact details and CV download

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Laragon (local development)

No frameworks or external libraries are required.

## Features

- Responsive design for desktop and mobile
- Mobile navigation menu
- Project filtering and expandable project details
- Simple animations and hover effects
- Downloadable CV
- Email contact and copy-to-clipboard feature
- Keyboard navigation and reduced-motion support

## How to Run

The website can be opened directly in a browser without installing anything.

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your browser.

Alternatively, you can run it using Laragon:

1. Place the project folder inside `C:\laragon\www\`.
2. Start Apache in Laragon.
3. Open `http://localhost/arissa_portfolio/` in your browser.
